# AIX — Artificial Intelligence Transformation Centre

Demo of the single-page website for the **Artificial Intelligence Transformation Centre (AIX)**, a strategic collaboration between the Malaysian Communications and Multimedia Commission (MCMC) and Multimedia University (MMU).

**Live demo:** https://teohsingjian02.github.io/aix-website/

This preview is for review only. It is not the official AIX site.

## Built with

- Plain HTML, CSS and JavaScript, with no framework or build step.
- Roboto for text and Anton for display headings, both from Google Fonts.
- A photo slider with a scanner-style transition, a neural-network canvas and a 13-laboratory carousel, with scroll animations throughout.

## Run locally

Open `index.html` with VS Code **Live Server**, or run any static file server in this folder.
